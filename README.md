# Инкогнито — меню по QR-коду

Мобильное меню кальянной «Инкогнито» (Бузулук). Позиции, цены, описания и фото берутся из Google Таблицы, поэтому меню можно менять, не трогая код.

Таблица: https://docs.google.com/spreadsheets/d/1Y99Y7D2Tst7Nj585W9rrruAH_Qe4LT-6AcQhtS6UFiU/edit

## Как выложить на GitHub Pages

1. На github.com нажмите **New repository**, назовите его, например, `incognito-menu`, тип **Public**, создайте.
2. В новом репозитории нажмите **uploading an existing file** и перетащите **всё содержимое** этой папки: `index.html`, `README.md`, `.nojekyll` и папку `img` целиком. Нажмите **Commit changes**.
   - Файл `.nojekyll` скрытый: на Mac покажите скрытые файлы сочетанием Cmd+Shift+. в окне Finder.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через 1–2 минуты сверху появится адрес вида `https://ВАШ-ЛОГИН.github.io/incognito-menu/`. Это ссылка на меню: откройте её на телефоне.
5. Сделайте QR-код с этой ссылкой (любой генератор QR) и разместите на столах.

## Как менять меню

Всё редактируется в Google Таблице, подробная инструкция — на вкладке **«Инструкция»**.

- **Меню** — одна строка = одна позиция: раздел, название, краткая подпись, подробное описание, объём, цена, фото, показывать да/нет.
- **Разделы** — порядок карточек на главной, их подписи, фото и пометки.
- Несколько объёмов и цен — через вертикальную черту: `1 л|2 л` и `250|400`.
- Пустая цена — на сайте будет «уточняйте», `0` — «бесплатно».
- Изменения видны после обновления страницы меню (обычно в течение пары минут).

### Фото
- **Через Google Диск:** загрузите фото, нажмите «Поделиться» → «Все, у кого есть ссылка», скопируйте ссылку и вставьте в колонку «Фото». Лучше квадратные снимки на тёмном фоне, от 800×800 px.
- **Через GitHub:** положите файл в папку `img/items` (например, `mojito.jpg`) и впишите в колонку «Фото» только имя файла: `mojito.jpg`.
- Если у позиции нет фото, показывается фото её раздела.

### Доступ к таблице
Таблица должна быть открыта по ссылке **для просмотра** («Все, у кого есть ссылка» → «Читатель»), иначе сайт не сможет её прочитать. Редактировать могут только те, кого вы добавили редакторами.

## Если таблица недоступна
Сайт показывает последнее успешно загруженное меню, а при самом первом открытии — встроенную копию меню из `index.html`.

## Что меняется в коде (`index.html`)
Это редкие правки, их удобно вносить прямо на GitHub (карандаш «Edit» у файла):
- часы работы — константа `HOURS`;
- правила — константа `RULES`;
- советы «Как курить, чтобы кальян не горчил» — поле `tips` у раздела «Кальян» в `MENU`;
- приветственное окно — блок `<div class="welcome">`;
- телефон и адрес — подвал `<footer class="foot">` и константа `ADDRESS`;
- таблица — константы `SHEET_ID` и `SHEET_GIDS` (номер вкладки — число после `gid=` в адресе таблицы).

## Структура
```

img/emblem.png         маска для приветственного окна
img/wordmark.png       надпись «ИНКОГНИТО hookah lounge» в подвале
img/icon-64.png        иконка вкладки браузера
img/icon-180.png       иконка для экрана «Домой» на iPhone
img/categories/*.jpg   фото разделов
img/items/*.jpg        фото позиций
```
