# Инкогнито — меню по QR-коду

Мобильное меню кальянной «Инкогнито» (Бузулук). Позиции, цены, описания и фото берутся из Google Таблицы, поэтому меню можно менять, не трогая код.

Таблица закрыта для посторонних (ссылка есть только у владельцев). Сайт получает меню через скрипт Google (тот же, что принимает заказы): он отдаёт только вкладки «Меню», «Разделы», «Баннеры» и «График».

## Как выложить на GitHub Pages

1. На github.com нажмите **New repository**, назовите его, например, `incognito-menu`, тип **Public**, создайте.
2. В новом репозитории нажмите **uploading an existing file** и перетащите **всё содержимое** этой папки: `index.html`, `README.md` и папку `img` целиком. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через 1–2 минуты сверху появится адрес вида `https://ВАШ-ЛОГИН.github.io/incognito-menu/`. Это ссылка на меню: откройте её на телефоне.
5. Сделайте QR-код с этой ссылкой и разместите на столах.

## Как менять меню

Всё редактируется в Google Таблице, подробная инструкция — на вкладке **«Инструкция»**.

- **Меню** — одна строка = одна позиция: раздел, название, краткая подпись, подробное описание, объём и цена, фото, показывать да/нет.
- **Объём и единица:** в «Объём» — только число (1, 0,5, 70), в «Ед.» — выберите из списка: шт, л, г, час. На сайте получится «0,5 л», «70 г», «1 час».
- **Два объёма с разными ценами** (например, чай 1 л и 2 л): первый вариант — в «Объём», «Ед.», «Цена», второй — в «Объём 2», «Ед. 2», «Цена 2». Можно добавить и третий («Объём 3», «Ед. 3», «Цена 3»). Старая запись через черту (`1 л|2 л` и `250|400`) тоже работает.
- **Разделы** — порядок карточек на главной, их подписи, фото и пометки. Новая строка = новый раздел.
- Пустая цена — на сайте будет «уточняйте», `0` — «бесплатно».

### Фото и видео
Все фото и видео берутся из таблицы по имени файла, файлы лежат на GitHub. В коде сайта картинок меню нет.

| Вкладка | Колонка | Папка на GitHub |
|---|---|---|
| «Меню» | «Фото», «Видео» | `img/items` |
| «Разделы» | «Фото», «Видео» | `img/categories` |
| «Баннеры» | «Фото», «Видео» | `img/banners` |

- В ячейку пишется только имя файла, например `mojito.jpg` или `hookah.mp4`, без папки.
- **Фото** (.jpg) нужно всегда: его видно сразу. **Видео** (.mp4) — по желанию: оно появляется поверх фото, когда загрузилось и заиграло. Если видео не загрузилось или грузится дольше 8 секунд, гость просто видит фото.
- В списке позиций показывается только фото (видео грузится, когда гость открывает позицию).
- **Включить видео** (да/нет) — колонка рядом с «Видео» на каждой вкладке. «да» или пусто — играет видео (видео в приоритете), «нет» — показывается фото; имя видео можно не стирать.
- **Баннеры** фирменных позиций — на вкладке «Баннеры», одна строка = один баннер: Раздел, Позиция (название как в «Меню»), Фото, Видео, Показывать (да/нет — включить или выключить баннер), Включить видео. Порядок строк = порядок баннеров на сайте. Все баннеры выключены — больших карточек нет.
- Фото можно дать и ссылкой на Google Диск (файл открыт по ссылке для просмотра); видео — только файлом на GitHub.
- Если у позиции нет ни фото, ни видео, показываются фото и видео её раздела; если нет и их — крупная буква названия.
- Заменили файл на GitHub с тем же именем — гости увидят новый в течение ~10 минут.

### Доступ к таблице
Таблица должна быть открыта по ссылке **для просмотра** («Все, у кого есть ссылка» → «Читатель»), иначе сайт не сможет её прочитать.

## Если таблица недоступна
Сайт показывает последнее успешно загруженное меню, а при самом первом открытии — встроенную копию меню из `index.html` (только текст, без фото).

## Что меняется в коде (`index.html`)
Редкие правки, их удобно вносить прямо на GitHub (карандаш «Edit» у файла):
- часы работы — меняются в таблице, вкладка «График»; константа `HOURS` — запасной график, если вкладка недоступна;
- правила — константа `RULES`;
- советы «Как курить, чтобы кальян не горчил» — поле `tips` у раздела «Кальян» в `MENU`;
- адрес приёма заказов и вызова официанта — константа `ORDER_URL` (скрипт Google, который пересылает заказ в Telegram; токен бота хранится в самом скрипте, не на сайте);
- приветственное окно — блок `<div class="welcome">`;
- телефон и адрес — подвал `<footer class="foot">` и константа `ADDRESS`;
- меню берётся по адресу `ORDER_URL` + `?menu=1` (константа `MENU_URL`); адреса самой таблицы в коде нет.
- заказы принимаются только по ссылкам из QR-кодов вида `?table=5&k=КОД`. Ссылки для всех столов: в таблице меню «🤖 Бот заказов» → «Ссылки для QR-кодов столов» (вкладка «QR-коды», её не публиковать). «Сменить секретные коды столов» делает старые QR-коды недействительными.
- цены в заказе скрипт берёт из вкладки «Меню», а не с телефона гостя; позицию, которой нет в меню, заказать нельзя.

## Структура
```
index.html             сайт целиком: стили, скрипт, запасная копия меню (текст)
img/logo.png           логотип на главной
img/emblem.png         маска для приветственного окна
img/wordmark.png       надпись «ИНКОГНИТО hookah lounge» в подвале
img/icon-64.png        иконка вкладки браузера
img/icon-180.png       иконка для экрана «Домой» на iPhone
img/categories/        фото (.jpg) и видео (.mp4) разделов
img/items/             фото и видео позиций
img/banners/           фото и видео баннеров фирменных позиций
```

## Форматы фото

| Где | Пропорции | Размер | Папка |
|---|---|---|---|
| Карточка раздела | 1:1 | 1000×1000 | `img/categories` |
| Первая (высокая) карточка | 1:2 | 700×1400 | `img/categories` |
| Позиция | 1:1 | 1000×1000 | `img/items` |
| Баннер фирменной позиции | 16:9 | 1200×675 | `img/banners` |
| Видео | те же пропорции, что у фото | квадрат 720×720, баннер 1200×676 | та же папка, что у фото |

Тёмный фон, предмет в центре (на баннере — справа), JPG до 300 КБ, видео MP4 (H.264, без звука) до ~600 КБ, 3–4 секунды по кругу. Фото на карточке раздела стоит сверху и снизу уходит в чёрный — под ним текст.
